## 一、筛选规则

| 规则 | 说明 |
|---|---|
| 含人物即剔除 | 背景里出现人的身体、手臂、脸，一律不用。定妆参考必须只有一只狗 |
| 非原始照片剔除 | 微信通话截图（界面 + 人脸小窗）一律不用，会污染模型的「画面里有什么」判断 |
| 重复剔除 | 同一张图的不同压缩版本只保留信息量最高的 |
| 构图不完整剔除 | 主体被裁到只剩局部、无法判断体型比例的 |
| 一图一职责 | 每张只负责一个明确的视角或姿势 |

> **踩过的坑（不要退回贴图方案）**：
> 1. **坐标搞错坐标系** —— 补全区一开始用的是原图坐标，却作用在已裁剪的图上，
>    补丁框整个落在画面外，等于什么都没补。
> 2. **羽化遮罩太弱** —— 「整块矩形 + 大半径高斯模糊」做出来的遮罩中心只有 220/255，
>    合成后是半透明叠加，手只被"淡化"、没被"替换"。
> 3. **贴图会有矩形接缝** —— 换四种取样源（背毛 / 肋部 / 颈毛 / 左上）都能看出方框边界。
>    → 最终改用**拉普拉斯扩散修补**：把待删区域按周边已知像素平滑地"长"出来，
>    无接缝、无方块感，白毛区域观感自然。numpy 30 行实现，无需 opencv。

1. 毛太多
