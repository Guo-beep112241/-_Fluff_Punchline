## 技术路线（重要）

原计划用 MiniMax-H3 Ref2VA 逐镜生成（提示词见 `episodes/ep01/prompts/`），
但生成额度中途耗尽（`402 the remaining M Plan weekly limit ... cannot cover`），
图像、语音、配乐、视频四类接口同时不可用。

最终改为**全本地流水线**：

```
真实照片抠像 + 场景锚点合成首帧 → ffmpeg 数字推拉 → edge-tts 配音
→ 程序化环境音/音效/配乐 → ffmpeg 剪辑（字幕/片头/彩蛋/片尾/loudnorm）
```

所以成片是**照片驱动的动态分镜（motion-comic）**，不是逐帧生成的写实视频。
好处：零额度、可无限重跑、角色 100% 是真实的小六二；代价：没有真正的身体表演。
完整说明与「额度恢复后怎么换回真视频」见 `docs/交付说明_S1.md`。
