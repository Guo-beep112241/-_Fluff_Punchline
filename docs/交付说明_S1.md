## 二、技术路线（这一段必须看：中途被迫换了三次方案）

### 1. 原计划：MiniMax-H3 Ref2VA

`episodes/ep01/prompts/` 里 33 份六段式 H3 提示词是为此写的，`bible/series.md` §8 的口型结论也基于 H3 实测。

### 2. 实测：H3 额度耗尽（402）

```
{"code":402,"message":"the remaining M Plan weekly limit and account credits cannot cover this
MiniMax-H3 video generation; this task costs 347 credits ..."}
```
`docs/额度与成本.md` 已记录过同一问题，这次是额度池见底。

### 3. 降级：Hailuo 2.3 图生视频（先跑通，再被额度打断）

改用 **首帧图 + MiniMax-Hailuo-2.3（6s / 768P）**，实测可以生成 768×1376 竖屏视频，
运动自然（呼吸、耳朵抖动、头低位），第 1 集的镜 01/02/05 与 10 张首帧就是这条路线的产物：

- `20_生成结果/ep01/shots/ep01_sh01_v1_768p.mp4`（等 3 段真实 Hailuo 视频）
- `20_生成结果/ep01/frames/sh01–sh10.png`（真实 generate_image 合成帧）

随后 **图像、语音、配乐、视频的额度全部见底**，同一条 402 报错覆盖
`generate_image` / `synthesize_speech` / `batch_text_to_music` / `submit_video_generation`，
且一个成功未取回的任务把 credits 挂住，后续提交全部被拒。

### 4. 最终落地：全本地流水线

| 环节 | 最终做法 |
|---|---|
| 首帧 | `compose.py`：真实照片用 `rembg`（u2net）抠像 → 放进 9 张场景锚点图 → 颜色匹配 + 接触阴影 + 颗粒/暗角统一质感；脸部特写直接用整幅真照片（抠图在特写下必然穿帮） |
| 运动 | ffmpeg `zoompan` 数字推拉（缓慢 Push In / Pull Out），24fps |
| 配音 | `edge-tts` 逐句（9 个角色 9 个音色） |
| 环境音/音效/配乐 | `audio_lib.py` 程序化合成 |
| 剪辑 | ffmpeg：裁切 4.0–5.8s、字幕 `drawtext`（Hiragino Sans GB）、片头/片尾卡、彩蛋、concat、loudnorm |

**这与季纲里"AI 生成视频"的设想不同，必须说清楚**：成片是**照片驱动的动态分镜（motion-comic）**，
不是逐帧生成的写实视频。好处是**零额度、可无限重跑、角色 100% 是真实的小六二**；
代价是画面只有推拉与剪辑节奏，没有真正的身体表演。

## 三、怎么重跑 / 怎么换回真视频

```bash
cd ~/Movies/Xiaoliuer

# 1) 首帧（本地合成，零额度）
~/XiaoliuerVideoGen/venv/bin/python tools/compose.py --ep ep01 --force

# 2) 配音 + 环境音 + 配乐
~/XiaoliuerVideoGen/venv/bin/python tools/film_pipeline.py audio --ep ep01

# 3) 成片
~/XiaoliuerVideoGen/venv/bin/python tools/film_pipeline.py build --ep ep01
```

**额度恢复后（推荐路径）**：保留 `episodes/ep0X/shots.json` 不动，把 `film_pipeline.py` 的
`frames` 换成 `generate_image`、`videos` 换成 `MiniMax-Hailuo-2.3`（或 H3 Ref2VA，提示词在
`episodes/ep01/prompts/`），成片脚本无需改动——
`build` 只要发现 `20_生成结果/<ep>/shots/shNN.mp4` 存在，就自动用视频替代静帧。

## 四、已知限制（诚实清单）

1. **画面是静帧/拼贴 + 推拉，不是真实运动视频。** 拼贴镜头在特写下会露出抠图边缘，
   所以特写一律用整幅真照片，中远景才做"放进场景"。
2. **狗的动作与台词只在声音层发生。** 没有口型同步，靠侧脸/低头/遮挡与 V.O. 规避。
3. **场景锚点是 AI 生成的空景**（公告栏、走廊、宿舍、排练室、阶梯教室、小剧场、客厅、校园路、操场），
   同一集内反复出现，靠机位与推拉区分。
4. **彩蛋是真实素材**（幼犬 7 段 + 成年走路 1 段），保持手机原生的不完美。
5. **H3 的 33 份 Ref2VA 提示词暂时闲置**，等额度恢复可直接复用。
