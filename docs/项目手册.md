# 小六二短剧 · 项目手册

> **新会话从这里开始读。** 这是本项目的唯一入口文档，读完这一份就能接手全部上下文，不需要翻历史对话。

最后更新：2026-10-22

---

## 一、这是什么

给家里的萨摩耶「小六二」做**搞笑 AI 短视频短剧**，发抖音/小红书/视频号。

- **模型**：MiniMax H3（`MiniMax-H3`）
- **画幅**：竖屏 9:16
- **风格**：主线保持真实狗形态；偶尔穿插拟人化彩蛋
- **主线**：成长线为主（从 3 个月大到新家到现在），友情线为辅
- **场景**：家里（客厅）和小公园
- **第一阶段**：做 1 集 30–45 秒试播集，验证风格后再量产

**核心判断**：这个项目的成败**不取决于剧本创意，而取决于跨镜头的小六二形象一致性**。所有流程设计都围绕这一点。

---

## 二、四条铁律

违反任何一条都会毁掉项目。

1. **原片只读，永不修改。** 原片是唯一找不回的东西。所有压缩/裁剪/转码只作用在副本上（`10_工作素材/`）。
2. **文件名必须自我表意。** `253_1734673898.mp4` 这种名字在 AI 流程里是灾难——提示词写「使用 `<Picture 1>`」时你不知道 Picture 1 是哪张狗。
3. **一张参考图只给一个职责。** 形象归形象、场景归场景、动作归动作、运镜归运镜。绝不要求一张图管所有。喂矛盾的多张图，模型会在它们之间摇摆，产出谁都不像的「平均脸」。
4. **每镜一个动作、一个主运镜，时长 4–6 秒。** 超过就拆镜。塞两个动作必失控。

---

## 三、H3 硬约束（踩过就回不来）

| 项 | 限制 |
|---|---|
| 时长 | **4–15 秒整数秒**，不能 3.5 秒 |
| 分辨率 | 768P 或 2K |
| 单次任务 | **= 一个镜头**。不存在「一次生成一集」 |
| 参考图 | ≤9 张，单个 ≤30 MB，宽高各 256–5760 px |
| 参考视频 | ≤3 段，单段 2–15 秒，**总 ≤15 秒**，≤50 MB |
| 参考音频 | ≤3 段，总 ≤15 秒，且**不能单独使用** |
| 混合总数 | ≤12 个文件 |
| 提示词 | ≤7000 字符 |
| 生成耗时 | 15–30 分钟 |

**两个必须记住的**
- H3 **Max 不支持多模态参考**（只能首/尾帧），本项目必须用 H3.0
- 首尾帧模式与参考素材模式**互斥**，不能混用

## 七、下一步该做什么

### 你（用户）要做的

**1. 投放照片** — 每类 20–30 张候选，**不要提前改名/裁剪/压缩**：

```
~/Movies/Xiaoliuer/10_工作素材/characters/_incoming/puppy/   ← 最优先：3 个月大的
~/Movies/Xiaoliuer/10_工作素材/characters/_incoming/adult/   ← 现在的小六二
~/Movies/Xiaoliuer/10_工作素材/scenes/_incoming/             ← 客厅和小公园
```

用**隔空投送**传。不要用 iCloud 照片同步（那个目录结构没法直接当素材用）。

**2. 手机相册怎么找** — 按可靠性排序：
1. 相册 → 搜索框 →「人物与宠物」→ 找小六二的合集（命中率最高）
2. 搜狗的名字 / 「萨摩耶」
3. 搜家人名字（佳佳/恒姐/冰哥）找合照
4. 搜索框输入 `2024年11月` 之类，按日期定位

**⚠️ 不要整理整个相册。** 整理 10,000 张是几小时体力活，产出接近于零；找到 10 张合格照片只要 20 分钟。

**定妆照标准**（关键：**最好看的照片 ≠ 最适合当参考的照片**）：
- 脸**正面或接近正面**，不要纯侧脸
- 五官完整清晰，不被毛发糊住、不戴帽子墨镜
- 光线均匀，不要强烈顶光或逆光（金色逆光侧颜照很漂亮但没用，模型学不到脸型结构）
- 是**当前**的样貌（幼犬照和成犬照必须分开定版）
- 分辨率够高（原图，不是微信压缩过的）

**3. 开启 iCloud 同步**（等文件整理做完再开，避免剪映路径失效）：
系统设置 → Apple 账户 → iCloud → 云盘 → 同步文件夹 → 选 `~/Movies/Xiaoliuer`

### 我（AI）要做的

照片到位后：
1. 媒体预检：格式/尺寸/时长是否符合 H3 规范，不合规的在**副本**上处理
2. **挑定妆照**：逐张看候选，选出定版照，说明取舍理由
3. 出角色圣经、场景圣经、`asset_index.csv`
4. 出试播集剧本和分镜表
5. 写镜 01 的完整提示词 → **阶段 4 单镜头验证**（只生成 1 个镜头，先确认像不像小六二）

## 八、工作流与省钱策略

```
阶段 0 素材入库 → 1 圣经 → 2 剧本 → 3 分镜 → 4 单镜头验证⭐ → 5 批量生成 → 6 剪辑发布
```

**阶段 4 是风险闸门。** 跳过它直接批量生成是最容易犯的错。

**两级生成**（省钱核心）：
```
第一轮  768P + 提示词 → 每镜 2–3 个变体 → 挑最好的构图
第二轮  同一提示词出 2K → 只改一个变量微调
```

**返工预期 2–3 倍是正常的**，预算要留余量。

**一次只改一个变量**——形象不对改参考图，动作不对改动作描述，运镜不对改运镜词。同时改三处就无法归因。

## 九、笑点原则

**主线不让狗说人话。** 台词只由人类角色承担（画外音/字幕形式）。

笑点来自**「人类的错误解读 vs 狗的真实动机」**，不是狗做人的动作。狗只做真实犬类行为（探、冲、咬、挤、趴、歪头、炸毛）。

这样既避开肢体畸变风险，喜剧结构也更好——「大人越认真、越错」比狗会说话好笑。

**人类角色默认弱出镜**：声音、画外音、手部特写、背影。观众听得出是姐姐/妈妈/爸爸就够了——真人肖像一致性比狗难得多，还涉及隐私。
