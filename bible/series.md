## 2. 世界观

### 2.1 世界规则（五条硬规则，任何一集都不能违反）

| # | 规则 | 内容 |
|---|---|---|
| **R1** | **画面里始终是一条萨摩耶狗** | 不变成人、不长手、不穿人衣服做人的动作。变的是「它说什么、在什么场景」 |
| **R2** | **它说人话，而且是主线** | 中文流利、有包袱、有怯场，不是彩蛋、不是拟人化音效 |
| **R3** | **第一人称自述** | 内心独白用画外音（V.O.），第一人称「我」。这是全系列唯一的叙事视角 |
| **R4** | **家庭是背景音** | 佳佳（姐）、恒姐（妈）、冰哥（爸）只以声音 / 手 / 影子 / 背影出现，不是主线角色 |
| **R5** | **大学生活是真的** | 宿舍熄灯断电、查寝、点外卖、微信群、抢选修课、期末周、快递驿站、社团招新、导师单独谈话、排练室、毕业设计、找工作 —— 全部按真实流程写，不写悬浮童话 |

### 2.2 「说人话的狗」在人类社会里的四个层次（现实感来源）

小六二确实会说人话。但人和「说人话的狗」相处的真实状态是分层的，喜剧就长在这个落差里：

| 层次 | 谁 | 怎么对待它说话 | 后果 |
|---|---|---|---|
| **① 完全听得懂** | 家人（佳佳、恒姐、冰哥） | 从小一起长大，听得懂，还习惯它贫 | 唯一能接住它的人；**也是它唯一能当捧哏的人** |
| **② 半信半疑** | 同学、室友 | 信了，但不当回事，把它当"会玩梗的狗" | 愿意陪它玩，但接不住它的专业内容 |
| **③ 当成训练过的把戏** | 老师、辅导员、评委 | "这狗被训练过，会叫词儿" | 误读产生的评价反而变成它的"专业认证" |
| **④ 完全听不懂** | 校外的人、路人、观众席 | 只听见"汪汪" | 它的段子只有**家人**和**镜头前的观众**听得懂 |

> **这一层结构是全系列的情感内核**：
> **它有一个专业，但没有一个能听懂这个专业的人。**
> 除了家人，和我们。

### 2.3 核心喜剧引擎：「在人类眼里，它是个小孩」

它不是以"狗"的身份进大学。它是以**特长生**进的。

- **入学方式**：特殊才能通道。材料是一段贯口录音、若干个爪印，和一份"本人无手"的说明。
- **面试现场**：评委听不懂它在说什么，只看见一个穿红围巾、一本正经、摇头晃脑的"小孩"在说相声。评委一致评价：**「这孩子有台风。」**
- **此后全程**：所有人类的反馈，都是对一个他们以为存在的"小孩"的反馈。

> **这为什么好用**：
> 1. 它把"狗说人话"从玄幻设定变成了**喜剧设定**——笑点不是"狗怎么会说话"，而是"人类完全误会了它"。
> 2. 它天然解决"狗做人的动作"的技术雷区：**小孩在台上也不做复杂手势**。紧张、抠手、眼神乱飘、忘词、站着不动 —— 这些对狗全是自然动作，对小孩也是真实表现。**它不需要做任何狗做不到的模仿。**
> 3. 它让"人类出镜"完全不必：一个小孩的观众印象，用**声音 + 手 + 影子**就能立住。

### 2.4 主线世界（这一季发生在哪）

- **学校**：城东大学（虚构，避免真实学校）。老校区，宿舍楼是那种楼道里永远飘着泡面味的六层板楼。
- **院系**：文学院 · 曲艺系 · **相声方向**。大一。
- **社团**：相声社。社长是个大四男生，只出声音。社员一共十一个人，一半是来拍照的。
- **小剧场**：学校教三楼的小黑匣子剧场，座位一百二十，演出用手机手电筒打侧光。
- **家里**：客厅有沙发、地毯、茶几、一双常客拖鞋。

## 3. 小六二的大学身份与专业设定

### 3.1 身份卡

| 项 | 内容 |
|---|---|
| 名字 | 小六二（"六二"来源待家人确认，暂不写死） |
| 物种 / 性别 | 萨摩耶 / 公 |
| 年龄 | 1 岁半（相当于人类 20 岁） |
| 身份 | 城东大学 文学院·曲艺系·相声方向 大一 |
| 身份合法性 | 特殊才能通道入学。**材料里有六个爪印** |
| 专业 | 相声。**还在努力学、经常搞砸、还没出师** |
| 行当 | 想做**逗哏**（出彩的那一个），实际更像**单口**（一人分演两角） |
| 导师 | 一位只出声音的女老师，姓什么不出现，喊"小六二同学" |
| 挂科风险 | 会挂《大学语文》，因为论文交不出来 |
| 会什么 | 说学逗唱里的"说"和"逗"；贯口能背八千字；绕口令全灭；学（模仿）勉强；唱跑调 |
| 不会什么 | **任何需要手的事**：写字、填表、打字、签字、端东西、递话筒 |
| 口号 | 「相声讲究说学逗唱、手眼身法步。我手眼身法步一样没有，我只有一条尾巴。」 |

### 3.2 专业行话 → 狗的身体对应表（本系列最重要的设定表）

这是全季笑点的"词典"。**每个行话都必须在这一列里找到它的狗版本**，不允许绕开。

| 相声行话 | 人的做法 | **小六二的做法（狗的身体）** | 笑点强度 |
|---|---|---|---|
| **亮相** | 亮相眼、亮相足，把气势做出来 | **把尾巴竖起来，定住三秒**（第三秒忍不住去闻自己的尾巴） | ★★★ |
| **手眼身法步** | 手势、眼神、身段、法度、台步 | 手 → 耳朵往后贴；眼 → 歪头；身 → 转身（但永远不背对）；法 → 坐下说；步 → 外八走位 | ★★★ |
| **偷气换气 / 贯口** | 长段子里偷换气不露痕迹 | **腹式呼吸，偷不到气，只能偷着喘**。念到"蒸鹿尾儿"直接趴下 | ★★★ |
| **绕口令** | 嘴皮子利索 | 犬类口型结构，中文吐字天然含混。"鹿尾儿"念成"驴尾儿" | ★★☆ |
| **逗哏 / 捧哏** | 两个人 | **它自己分演两角**：逗哏是它，捧哏是"左边那撮毛"。切换靠低头闻一下 | ★★★ |
| **卖字眼儿** | 在词上做文章 | **最容易的一项**——它的嘴比人笨，但脑子不慢 | ★★☆ |
| **现挂** | 临场抓梗 | 它的"现挂"全靠真实的狗行为：打喷嚏、掉毛、追尾巴 | ★★★ |
| **攒底** | 最后一个包袱 | 它习惯把攒底做成"实况转播"（今天宿舍谁又干了什么） | ★★☆ |
| **报菜名** | 一口气报完 | 三段语音都发不完，微信 60 秒上限卡死 | ★★☆ |
| **单口相声** | 一个人演两个角色 | **它现在唯一的表演形式** | ★★★ |
| **下场** | 演员退场 | 它"下场"是趴下 —— 因为它的"亮相"趴得太久，站不住了 | ★★☆ |

### 3.3 成长线的核心态度变化（全季的情感弧）

> **它不需要变成人。它需要承认自己的"不是人"就是它的本事。**

| 阶段 | 集数 | 它的态度 | 标志性台词 |
|---|---|---|---|
| **一 · 硬撑** | Ep1–Ep2 | 「我要跟人一样。」拼命模仿人类的亮相、站姿、词。到处搞砸 | 「我今天亮相了。」（其实只是尾巴竖了 3 秒） |
| **二 · 偷懒** | Ep3–Ep4 | 意识到制度比技巧更难（选课、论文），开始嫌麻烦 | 「我能背八千字贯口，我连自己名字都写不出来。」 |
| **三 · 认命** | Ep5–Ep6 | 发现自己的缺陷就是它的风格：喷嚏当音效、侧身当亮相、背对当谢幕 | 「观众以为我在逗他们，其实我只是太紧张。」 |
| **四 · 收下** | Ep7–Ep8 | 接受"没人完全听得懂"，把表情包设成头像，把"能吃"当成职业规划 | 「能吃上饭。」 |

## 4. 性格档案

| 维度 | 设定 | 表现方式（必须是狗的动作） |
|---|---|---|
| **底色** | 认真、较真、爱面子 | 屡败之后不撒泼，只是默默趴下两秒再站起来 |
| **聪明** | 学东西极快，理解力强 | 一集之内能复述别人说过的话，但复述成"相声腔" |
| **笨拙** | 身体跟不上脑子 | 想做精细动作时，爪子会先动脑子才动 |
| **爱表现** | 有观众就兴奋 | 一有人看就原地转圈、尾巴狂摇 |
| **怯场** | 一旦被盯着就僵 | 紧张时不停舔鼻子（**这个动作天然遮挡嘴部，口型风险低**） |
| **嘴碎** | 爱讲道理、爱总结 | 每集结尾都要"总结一下"，总结得很差 |
| **记仇但记不住** | 室友抢了它的零食，三天后就忘了为什么生气 | 闻到零食味又开始摇尾巴 |
| **对家人撒娇** | 只在家人面前 | 听到恒姐的脚步声就往门口跑 |
| **招牌动作** | ① 舔鼻子（紧张）② 歪头（疑惑）③ 原地转圈（兴奋）④ 低头闻左边（切"角色"）⑤ 尾巴竖起定住（亮相） | 全部用真实行为，不拟人 |

> **成长线依赖**：① ④ ⑤ 在幼犬真实素材里已有近似动作（跑向镜头、叼拖鞋走、站立张望），可以直接做闪回。

## 5. 家庭关系与成长线

### 5.1 家庭三人

| 角色 | 关系 | 出场方式 | 说话特征 | 剧情功能 |
|---|---|---|---|---|
| **姐姐 · 佳佳** | 姐，大学生/上班 | 微信语音、视频通话、画外音、偶尔一只手 | 语速快、爱说"行吧""你开心就好"、打麻将背景声 | **唯一的捧哏**。她听得懂，所以她能接住梗。她也最忙 —— 排练只能远程 |
| **妈妈 · 恒姐** | 妈 | 画外音、厨房方向的声音、一只手（揉狗头） | 务实、爱问"这个能干嘛""能挣钱吗" | **外部检验器**。她代表"世俗标准"，负责把主角打回原形 |
| **爸爸 · 冰哥** | 爸 | 画外音、极偶尔的脚步 | 全季台词不超过 5 句，全是短问句 | **气氛调节器**。沉默本身好笑 |
| （未出场）| 室友 | 画外音、门缝影子、一双拖鞋 | 声音很年轻、爱抬杠 | 宿舍段的固定对手 |

### 5.2 家庭为什么听得懂（世界观补丁）

小六二从小在这个家长大。它刚到家的时候不会说话，后来某天忽然开口说了第一句——**家里没一个人大惊小怪**。这个"家里早就习惯了"的设定，是全系列不悬浮的支点：

- 家里人对它说人话**不稀奇**
- 家里人**听得懂但不当回事**（"我们家这狗贫"）
- 所以佳佳能当它的捧哏，但也随时会挂掉语音说"我信号不好"

### 5.3 真实素材的用法：每集末尾彩蛋（2026-10-23 用户拍板）

**真实照片和视频不作为叙事内的闪回，而是放在每一集的末尾当彩蛋。**

用户决策原话：「真实照片和视频放在每一集的末尾当彩蛋吧」。

这样处理有三个好处：① **画质断层不再是问题** —— 彩蛋本来就该看起来不一样，差异变成叙事资源而不是缺陷；
② **成长线不用塞进正片**，正片可以纯粹演"大学生小六二"；③ **每集都有一句"这是真的"的落点**，强化「这是我家真狗」的可信度。

**彩蛋的固定形式（每集最后 6–10 秒）**：

| 项 | 规范 |
|---|---|
| 位置 | 正片最后一个画面结束后，**必须**接一段彩蛋 |
| 长度 | **6–10 秒**，剪出 1–2 个动作即可，不要更长的片段 |
| 内容 | 真实照片 / 真实视频片段 |
| 视觉处理 | 裁成 9:16 + **加胶片颗粒 + 轻微褪色 + 保留手机原生的不完美**。**不要修得跟 AI 部分一样好看** —— 画质差异本身就是笑点的一部分 |
| 字幕 | 一行固定位置的小字，风格是「AI 演绎 vs 真实本人」的反差吐槽 |
| 声音 | 保留原始环境声，不配 BGM —— 一听就知道是"真的录的" |

**8 集彩蛋分配**（幼犬 7 段正好 7 集，第 8 集用成年素材收尾）：

| 集 | 彩蛋素材 | 呼应 |
|---|---|---|
| Ep1 | `x6_puppy_run_to_cam_06`（跑向镜头） | 呼应它咬走报名表就跑 |
| Ep2 | `x6_puppy_carry_slipper_07`（叼红拖鞋走） | 呼应它叼笔填表 |
| Ep3 | `x6_puppy_lying_toy_03`（趴着啃玩具） | 呼应它啃稿子 |
| Ep4 | `x6_puppy_stand_look_01`（站立张望） | 呼应它站在走廊等结果 |
| Ep5 | `x6_puppy_sit_04`（坐姿） | 呼应它坐着"说"了一整段 |
| Ep6 | `x6_puppy_stand_walk_02`（侧面行走） | 呼应它走台 |
| Ep7 | `x6_puppy_walk_approach_05`（走向镜头） | 呼应它刷手机后跑向镜头 |
| Ep8 | `x6_adult_char_ref_walk_splay_03.mp4`（成年走路 v3） | **长大成人了** —— 唯一一段成年彩蛋，放在最后一集收束全季 |

> ⚠️ **幼犬素材没有幼犬定妆图**，所以任何"生成幼犬镜头"都不可靠 —— **幼犬画面只能用真实视频**，不能生成。需要新的幼犬动作时，从 34 段原片里重新剪，不生成。

### 5.4 成年真实素材的用法

16 张真实照片 + 3 段定妆视频的定位：

| 素材 | 定位 |
|---|---|
| 16 张真实照片 | ① 作为 H3 参考图（**主力**）② 彩蛋里做"照片/截图"形式入片（手机相册、表情包素材、照片墙）③ 作为**静帧 + 关键帧动效**的静镜（零生成成本，剪映可做） |
| v1 / v2 定妆视频 | 作为 H3 参考视频（≤3 段、总 ≤15 秒的额度要用在刀刃上） |
| **v3 定妆视频（侧面走路 + 轻微外八）** | ⭐ **最珍贵的动态参考**。它是"小六二走路"的唯一权威动态样本。Ep2 练步、Ep5 走位、Ep6 上台全部以它作参考视频；Ep8 彩蛋也用它 |

## 7. 笑点体系

### 7.1 五类笑点（优先级从高到低）

| 类别 | 定义 | 例子 | 占比建议 |
|---|---|---|---|
| **A · 身体型** | 相声的专业要求 vs 狗的身体做不到 | 亮相只能摇尾巴；贯口撑不住气；蹲不下去 | **50%** |
| **B · 制度型** | 大学的制度 vs 狗无法参与 | 填表、抢课、论文、语音 60 秒、点名、查寝 | **25%** |
| **C · 认知型** | 人类对它的误读 | 评委说"这孩子有台风"；表情包"是不是拉裤子了" | **15%** |
| **D · 情感型** | 扎心反差，长线回收 | 「观众以为我在逗他们，其实我只是太紧张。」 | **10%** |
| **E · 语言型** | 行话与咬字的错位 | 卖字眼儿（它的强项）；绕口令全灭；"驴尾儿" | 跨类 |

> **创作纪律**：A 类必须占一半。任何一集如果 A 类不足，这集的"相声味"就塌了。

### 7.2 每集必须有的三个零件（编剧自检）

1. **一个 A 类身体笑点** —— 必须是"专业术语 → 狗的替代方案"的直接对照
2. **一个 B 类制度笑点** —— 必须是一个真实存在的大学生流程
3. **一个 D 类情感拧一下** —— 把本集的小痛点拧一次，不要每次都苦，要苦中带笑

外加：
4. **一个「安静两拍后反转」** —— 短剧最有效的节奏。反转前必须有真的安静（静帧/静音/无音乐）
5. **一个记忆点** —— 能落到具体画面上的东西（一个动作 / 一个视觉反差 / 一句金句），不能只有对白

### 7.3 可复用的台词句式引擎

| 句式 | 模板 | 例 |
|---|---|---|
| **定义反差式** | 「X，是 Y。我的 X 是 Z。」 | 「亮相，是把气势做出来。我的亮相是把尾巴竖起来。」 |
| **行话自曝式** | 「相声讲究 X —— 我只能 Y。」 | 「相声讲究手眼身法步。我手眼身法步一样没有，我只有一条尾巴。」 |
| **身体交底式** | 「我 X 的时候特别像人。可惜我 X 的时候不像狗。」 | 「我翻身的时候特别像人。可惜我翻身的时候不像狗。」 |
| **术语误用式** | 把相声术语用到不该用的地方 | 「我这叫打滚儿，我给你加个响的。」 |
| **反问自嘲式** | 「我妈问我学这个能干嘛。……能吃。」 | — |
| **家人反打式** | 家人一句朴素的实话，把主角的劲头卸掉 | 恒姐：「挺好的，饿了就回来吃。」 |

### 7.4 禁用清单（不许出现的梗）

| ❌ 禁用 | 原因 |
|---|---|
| 狗做复杂人类动作（挥手、比心、握手、写字、端碗、穿大褂做身段） | H3 必崩；且违背 R1 |
| 狗被踢、被吓、被伤害、死亡梗 | 掉粉、平台风险 |
| 拿学历/学校档次/残疾/疾病开玩笑 | 负面 |
| "狗不能说话所以好可爱"式的陈词滥调 | 已经过时，且和 R2 冲突 |
| 狗在校园里横冲直撞吓到人 | 违反真实感，且和"特殊才能通道学生"的人设冲突 |
| 泛泛的"哈哈哈哈哈"式无信息量笑话 | 无笑点结构 |

## 8. 声音与口型规范（技术侧最重要的约定）

> 依据：H3 一次只能生成一个镜头，音画同生成，但**狗说中文的口型同步是未验证项**。
> 本系列用一套约定把风险压到最低。**这是本设定文件里最需要严格执行的一节。**

### 8.1 台词分三类，各走各的路

| 类型 | 说明 | 口型风险 | 处理方式 |
|---|---|---|---|
| **① 画外独白（V.O.）** | 第一人称自述，全季叙事主力 | **无** | 后期配音，画面做动作。**占全部台词的 65–70%** |
| **② 画外人类** | 家人、室友、老师、同学 | 无 | 后期配音。**占 25–30%** |
| **③ 正面口播镜头** | 小六二正面对着镜头说 | **高** | 每集 **≤3 个**，且必须是最值钱的那句 |

### 8.2 口型三级标注（每集分镜表里必须标）

| 标记 | 含义 | 画面条件 |
|---|---|---|
| 🔴 | **高风险** | 正面、大嘴、说话。**每集 ≤3 个** |
| 🟡 | **中风险** | 3/4 侧、说话、嘴部可见 |
| 🟢 | **低风险** | 背对镜头 / 低头 / 嘴部被遮挡 / 只有环境音 / 无台词 |

### 8.3 「嘴部遮挡优先」镜头策略（本系列的招牌技术手法）

**用道具和姿势合法地遮住嘴，口型要求立刻下降，稳定性大幅提升。** 可用的遮挡手段：

- 叼着马克笔（当话筒）
- 鼻子埋进纸堆/稿子/纸箱
- 低头闻地面 / 闻左边那撮毛
- 舔鼻子（紧张时的真实动作，天然遮挡）
- 趴在垫子上、下巴贴地
- **背对镜头**（尾巴挡住整个身体 —— 顺便解决"亮相"问题）

> ⚠️ **硬约束**：任何 🔴 镜头，**必须先做一次技术验证**（见 §10 风险项）。
> 若验证失败，**全线降级为 🟢**（小六二全季几乎不出现正面说话镜头，只用 V.O.）。
> 这个降级不会让剧集垮掉 —— 设计上 V.O. 已承载 70% 的戏。

### 8.4 声音方案（2026-10-23 用户拍板：后期配音 · 男性少年音）

**决策**：台词走**后期配音**，H3 只出画面 + 环境音。

**小六二的声音设计**：**男性少年音**（用户指定）。

- 定位：清亮、带一点少年变声期的毛边，语速偏快但不油
- 关键：**不能太成熟**。成年男声会让「狗说人话」显得像配音演员在演；少年音才立得住「这是个二十岁的人」
- 关键：**不要装可爱**。不要刻意学狗叫、加鼻音、加"汪"式尾音 —— 那样会毁掉「它认真地把自己当人」这个核心
- 相声专业需要的地方要**说清楚、咬字准**（贯口、报菜名）；但要保留一点「含混」的底色，让「吐字不清」成为笑点而不是事故
- **情绪起伏靠台词本身**，不加音效式处理

**环境音按实际情况配置**（用户指定）：H3 原生音轨保留环境声与物理动作声，后期只补人声。
- H3 出：环境底噪、动作声（爪子、纸张、木地板、脚步）
- 后期出：小六二的人声、人类角色的人声、必要时补的音效（笔滚落、门、远处的广播）
- **背景音乐后期加**，H3 的 `non_diegetic_music` 只写氛围性的，不要让它抢戏

**具体分工**：后期在剪映里做。配音可以用任意中文 TTS 或真人，**逐句录**（不要整段合成），
这样语速、停顿、情绪都能逐句调。台词表由编剧在 `script.md` 里给出，每句带说话人和情绪提示。

## 9. 技术红线

1. 外形描述**只能**来自 `bible/characters.md`，逐字复用。不得因剧情需要改动毛色、眼睛、耳朵、体型、尾巴。
2. **耳朵仍是未解决偏差**（v2/v3 生成出来比真实偏大偏立）。v4 提示词需补 `small, neat triangular ears that sit close to the head, slightly folded forward at the tips`。**本系列不解决它，但所有镜头都应写这条。**
3. 屏幕内容一律后期（S13）。
4. 多人同框镜头**控制在每集 ≤2 个**，且只用于"背影 + 一只手"级别。
5. 每镜一个动作、一个运镜，4–6 秒。
6. **合规**：按《人工智能生成合成内容标识办法》（2025-09-01 施行），发布时需标注 AI 生成。片尾固定一行小字：「本片由 AI 生成 · 小六二不出镜真人」之类。抖音社区对「动物拟人/宠物说话」内容有额外规范，发布前需自查。
