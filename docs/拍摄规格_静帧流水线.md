# 拍摄规格 · 静帧驱动流水线（Ep1–Ep8 统一）

> 2026-10-24 建立。**这份文件是 Ep1–Ep8 逐镜生产的唯一技术规格。**
> 背景：MiniMax-H3 的 M Plan 周额度已耗尽（提交即 402），Hailuo 2.3 走老 Token Plan 额度可用。
> 因此全季改为 **「真实照片合成首帧 → 图生视频 → 后期配音/环境音」** 三段式。
> H3 的 Ref2VA 提示词仍然保留在 `episodes/ep01/prompts/`，额度恢复后可直接切换回 H3。

---

## 一、三段式流水线

```
① 首帧合成   generate_image（场景图 + 真实照片做参考，9:16 / 1K）
              → 20_生成结果/ep0X/frames/shNN.png
② 图生视频   MiniMax-Hailuo-2.3（input_image + reference_type=first_frame，6s / 768P）
              → 20_生成结果/ep0X/shots/shNN.mp4（768×1376, 24fps, 无声）
③ 声音与成片  TTS 配音（逐句）＋ 程序化环境音/SFX ＋ BGM ＋ 字幕
              → 30_成片/ep0X_final_9x16.mp4（1080×1920, 24fps, AAC 48k）
```

- 每镜 Hailuo 固定 6 秒，成片按台词长度裁到 4.0–5.8 秒（首尾各留 0.2s 余量）。
- 口型不做逐音节同步：沿用 `bible/series.md` §8 的结论 —— 台词主要走 V.O.，
  出现"说话"的画面用侧脸 / 低头 / 嘴部遮挡 / 背对，**不让狗正对镜头说长句**。
- 所有屏幕内容（微信、教务系统、表情包）**仍然全部后期**，不生成。

```json
{
  "ep": 2,
  "title": "左边那撮毛",
  "logline": "一句话梗概",
  "shots": [
    {
      "id": 1,
      "scene": "dorm",
      "dur": 5.0,
      "frame_prompt": "中文首帧合成指令，见 §三",
      "refs": ["10_工作素材/characters/_curated/adult/x6_adult_lying_full_02.jpg"],
      "motion": "English image-to-video prompt, what moves in the shot",
      "lines": [
        {"who": "xiao", "text": "相声得两个人。", "emotion": "neutral", "speed": 1.0}
      ],
      "sfx": ["paper_flutter"],
      "amb": "dorm",
      "caption": "可选：画面底部字幕（与台词不同时才写）",
      "egg": false
    }
  ],
  "egg": {"clip": "x6_puppy_carry_slipper_07.mp4", "caption": "彩蛋字幕"}
}
```

### 字段规则

| 字段 | 规则 |
|---|---|
| `id` | 从 1 连续编号 |
| `scene` | 见 §四 场景表；决定首帧的场景图、环境音预设 |
| `dur` | 4.0–5.8，**默认 5.0**；只有一句短台词时 4.0，长句 5.5–5.8 |
| `frame_prompt` | 中文，2–5 句，**必须**包含：景别机位、狗的具体姿态与表情、场景里的关键道具位置、光线、"画面里不要出现任何文字"。以「把第二张图里这只萨摩耶放到第一张图的场景里」开头（`refs` 里**第一张必须是场景图以外的姿态照**，场景图由 `scene` 自动加在最前，见下） |
| `refs` | **姿态参考照**（1–2 张），从 `10_工作素材/characters/_curated/adult/` 里选；不要选正对镜头吐舌的 `x6_adult_face_front_tongue_01.jpg` 当主参考 |
| `motion` | 英文，1–3 句：只有**一个**主要动作（歪头/耳朵抖/尾巴尖摆/眨眼/呼吸起伏/低头嗅/爪子刨地/转头看），镜头写 `static camera`，结尾加 `realistic handheld phone footage, no text` |
| `lines` | 0–2 句；**每句 ≤ 18 个汉字**；合计朗读时长 ≤ 5 秒。`who` 见 §五 |
| `sfx` | 0–3 个，见 §六 音效名 |
| `amb` | 一个环境音预设，见 §七 |
| `caption` | 只在**没有台词**但需要一行说明时写，≤ 18 字 |
| `egg` | 固定 false（彩蛋单独在顶层 `egg` 里） |

**首帧合成的参考图顺序（流水线自动拼）**：
`<Picture 1>` 场景图 → `<Picture 2..n>` 你给的 `refs`。
所以 `frame_prompt` 里必须用「第二张图」指狗（只有一张 ref 时也是第二张）。

## 三、`frame_prompt` 写法（最重要的字段）

模板：

```
把第二张图里这只萨摩耶放到第一张图的<场景描述>里。<景别/机位>：<特写/近景/中景/全景>，<低机位贴地/俯拍/3-4侧45度/正侧>。
它<姿态>，<表情/耳/尾的细节>。<道具位置>。保持这只狗的<脸型圆、眼睛大而圆、耳朵小三角贴头、口鼻短宽、毛色纯白不是米黄、体型偏瘦腿长>与第二张图完全一致，不要改变它的外形。
<光线>。<质感：写实手机拍摄、自然光、略有噪点>。画面里不要出现任何文字、标识或水印。
```

几条硬经验（都是试出来的）：

1. **姿态必须写清楚是趴 / 坐 / 站 / 侧躺 / 背对**，并写清身体朝向和视线方向。不写，模型会给一个"标准站姿"。
2. **"3/4 侧"要写成「身体朝右前方、脸转向镜头左前方 45 度」**，抽象角度模型理解不稳定。
3. **不要要求狗做人类动作**（招手、比心、握手、端东西）。真实犬类动作：趴、坐、歪头、嗅地、刨地、抖毛、转圈、叼东西、吐舌、舔鼻子。
4. **画外的人类只出现手 / 腿 / 背影**，且尽量不入画。
5. 场景里**不要出现任何文字**（海报、黑板、屏幕都留白，文字后期叠）。
6. 同一个场景尽量用同一机位族（低机位贴地 / 平视 / 俯拍），跨镜切换才不会崩空间感。

## 八、每集必须有的结构（沿用 `bible/series.md` §7.2）

1. 一个 **A 类身体笑点**（相声术语 → 狗的替代方案）
2. 一个 **B 类制度笑点**（真实大学生流程）
3. 一个 **D 类情感拧一下**
4. 一个 **「安静两拍后反转」**（该镜 `amb` 用 `silence`，台词留空 1.5–2 秒）
5. 一个 **记忆点**（能落到具体画面上）
6. 结尾 **彩蛋**（真实幼犬/成犬素材，6–8 秒，顶层 `egg`）
7. 片头卡 + 片尾卡（AI 生成合规标识）由成片脚本自动加，**不占镜头**

**集内节奏**：起 4–5 镜 → 承 8–10 镜 → 转 5–6 镜 → 合 3–4 镜，总 20–26 镜，成片 1:50–2:30。
