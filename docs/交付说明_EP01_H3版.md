## 三、声音方案

| 角色 | 音色 | edge-tts voice | 基线语速 |
|---|---|---|---|
| 小六二 | 清亮少年男声（变声期毛边、语速偏快） | zh-CN-YunxiNeural | +12% |
| 甲·逗哏 | 清亮偏快 | zh-CN-YunyangNeural | +26% |
| 乙·捧哏 | 偏低偏憨 | zh-CN-YunjianNeural | +20% |
| 边牧 | 清亮爱抢话 | zh-CN-YunxiaNeural | +24% |
| 阿拉斯加 | 低沉嗓门大 | zh-CN-YunjianNeural | +8% |
| 小边牧 | 童声只喊短句 | zh-CN-XiaoyiNeural | +26% |

- 逐句生成，不整段合成；文件名 `{who}_{台词前 14 字}.mp3`，角色可辨。
- 不装可爱、不加鼻音、不加「汪」。
- **语速上限实测 = 7.3 字/秒**（用 ASR 转写逐字比对扫 7 档得出，6.6 字/秒 100% 准确、7.9 字/秒崩到 51%）。
  最密的镜（镜09 / 镜11）落在 6.5 字/秒，语速倍率只用到 1.27。
- **每句都裁掉 edge-tts 自带的约 0.5 秒首尾静音** —— 这一步让 36 句整体腾出十几秒，
  是「台词塞得进镜长」的关键（详见 `docs/额度与成本.md` 第八节）。

### 成片响度（实测 -15.2 LUFS / 真峰 -1.7 dBFS）

原始混音是「对白脉冲 + 极轻房间底噪」：测出来 **input_i = -25.2 LUFS 而 input_tp = +2.3 dBFS**
（波峰因数 27 dB）。直接套 loudnorm 会把限制器逼到极限，压完峰平均又掉回 -17 LUFS。

成片走**两遍 loudnorm（linear=true）+ 兜底限制器**（`tools/film_pipeline.py` 的 `cmd_build`）：

```
第一遍：loudnorm=I=-14.0:TP=-2.0:LRA=30:print_format=json     # 只测量
第二遍：loudnorm=I=-14.0:TP=-2.0:LRA=<测得>:linear=true:
          measured_I=…:measured_TP=…:measured_LRA=…:measured_thresh=…:offset=…
        → alimiter=limit=0.668:level=disabled:attack=1:release=50
```

- `linear=true` = **纯静态增益，不改动态**。这是保住「半秒空」的关键。
- 实测结果：**-15.2 LUFS / 真峰 -1.7 dBFS**，两个指标都达标。
- `cmd_build` 末尾会回读实测响度并打印，构建完就能确认，不用另外量。

> **踩过的坑（别再退回旧链）**
>
> 旧链是 `acompressor=threshold=-30dB:ratio=4:attack=3:release=120:makeup=8` + 单遍 loudnorm。
> 看起来能达标（-16.1 LUFS / -1.9 dBFS），但它**把镜25 的半秒空压没了**：
>
> - `acompressor` 的 `makeup` 是**倍数**不是 dB（8 → 实际 +9.4 dB 整体增益）；
> - `threshold=-30dB / ratio=4` 正好落在对白段上，把台词自身的波峰因数压掉，
>   台词均值从 -25.5 dB 掉到 -34.6 dB —— **安静段没被压、对白被压**，
>   于是「台词 → 半秒空」的落差从 13.6 dB 塌成 4.8 dB，第⑦条自检永远过不了。
>
> 逐级隔离实测（母版前 raw 落差 13.6 dB）：
>
> | 母版环节 | 台词→空档跌落 | 结论 |
> |---|---|---|
> | 母版前 raw | 13.6 dB | ✅ 内容层是对的 |
> | 只加 `acompressor` r4 | **4.8 dB** | ❌ 一级就吃掉 8.8 dB |
> | 只加 `loudnorm`（动态） | 13.3 dB | ✅ loudnorm 本身不伤动态 |
> | 只加 `alimiter` | 13.8 dB | ✅ 限制器不伤动态 |
> | **两遍 linear loudnorm + limiter** | **9.0 dB** | ✅ 当前采用 |

### 音层层级（这一层之前是坏的）

初版各镜 `bgm_gain=0.16`，算下来**音乐在混音内落到 -37.0 dB，而房间底噪也在 -37.0 dB** ——
音乐被底噪完全掩蔽，等于没铺音乐。这是「声音听起来不行」的直接原因。

现在的层级（`tools/fix_ep01_mix.py` 字段级回写 `shots.json`）：

| 层 | 混音内电平 | 相对对白 | 配置 |
|---|---|---|---|
| 对白 | ≈ -23 dB | 0 | 台词层，音量 1.0 |
| 音乐 | ≈ -32 dB | -9 dB | `bgm_gain` 0.30（镜26 = 0.40，音乐放大） |
| 房间底噪 | ≈ -39 dB | -16 dB | `amb_gain` 0.75 |
| 音效 | ≈ -35 dB | -12 dB | 音量 0.85 |

导出分层后实测（`20_生成结果/ep01/stems/`）：voice **-30.9** > bgm **-32.7** > sfx **-35.2** > amb **-39.8** dB，
四档分明。

### 镜25 的半秒空（`bgm_gap`）

- **坑：`volume` 滤镜的 `eval` 默认是 `init`** —— 表达式只在初始化时算一次，
  里面的 `t` 根本不随时间变，**静音窗会完全失效**（实测 t=2.5s 仍是 -21.1 dB）。
  必须显式写 `volume=eval=frame:volume='if(between(t,…),0,1)'`，表达式才会逐帧按时间戳求值。
- 镜25 配置：`bgm_gap: [2.25, 2.75]`（台词结束 2.25s 起，留半秒），笑声 2.80s 进。
- 成片实测电平曲线：台词段 -14.9 dB → **空档 -25.6 dB** → 笑声起来 -12.4 dB，
  中间有 **10.7 dB 的凹陷**；自检脚本量到的「台词段 → 空档段」跌落 **8.6 dB**（要求 ≥6）。

### 分层素材（供自己配音）

用户可以自己配音，故另导出分层 WAV（`20_生成结果/ep01/stems/`），**与成片严格同长同起点**：

| 文件 | 内容 | 时长 | 实测电平 |
|---|---|---|---|
| `bed.wav` | **铺底总轨**（音乐+底噪+音效，不含人声）—— 直接对着它录人声 | 148.0s | -29.5 dB |

> 实现坑：一次只 map 一层时，滤镜图里其它层若也建了输出分支，会变成独立输出流，
> 而 wav 只能写一条音轨（`wav muxer does not support more than one stream of type audio`）。
> 做法是**只为目标层建图**（`build_audio_graph(..., only_layer=…)`），别的一概不建。

### 字幕

- 底部安全区 y = h − 420，黑边白字（borderw 3 / black@0.75），fontsize 46。
- **逐句时间窗字幕**：一句一屏，按该句实际入点与时长开窗（`enable='between(t,...)'`），
  不是把整镜台词糊在一起。
- 每行 ≤ 13 个字；折行优先落在标点处（先按标点切语义段再装箱），不会出现「真实本 / 人」这种断词。

### H3 平台约束（踩过的坑）

| 约束 | 值 |
|---|---|
| 时长 | 4–15 整数秒（**3s 会被拒**） |
| 分辨率 | 768P / 2K |
| 比例 | 9:16 |
| 参考图 | ≤ 9 张，**前 5 张免费**，超出 ¥0.20/张 |
| 参考视频 | ≤ 3 个、总时长 ≤ 15s，且**按输出分辨率同价计费**（本集不用） |
| 提示词 | ≤ 7000 字符 |
| **并发** | **同时最多 3 个「已提交未查收」的任务**，多一个报 429 |
| 额度 | 按秒线性计价，约 69.4 credits/秒 |

**槽位靠「查询」释放，不是靠「取回」释放** —— 任务跑完但没被查过，槽位还占着。
所以投递必须是「每轮先查收全部 → 把在飞数补到 3 → 提交下一镜」的循环，不能一次批量提交。

## 五、已知限制（诚实清单）

1. **「不爱开心的」在快速语速下可能听成「我爱开心的」** —— 这是这句本身的歧义（慢速也一样），
   不是加速造成的。字幕完整，观众可交叉验证。
2. **H3 的角色一致性靠参考图 + 逐字复用描述**，不是严格的同一性保证。
   本集首轮就因为「真实照片 vs 文字描述」打架导致全身偏蓬松偏胖，换成定妆版参考图后重拍 18 镜才拉回来。
3. **H3 输出原生带音轨**，成片里 H3 的音轨被丢弃（只用我们自己的配音+音层），原片只读不动。
4. 镜25 的「半秒空」是用 BGM 时间窗静音实现的，不是真正的全静音（房间底噪仍在，符合制作令「只留房间底噪」）。
5. 成片真峰实测 **-1.9 dBTP**，比要求的 -1.5 dB 略保守 —— 为了 AAC 编码后不过冲。
6. **逐镜抽帧验收是单帧判定**：能查出「人类出镜 / 狗做人类动作 / 画面有可读文字」这三类硬违规，
   但对「拍两下地板」「抬后腿挠脖子」这类**动作**会误判为不吻合（单帧看不到动作过程）。
   本集 78 帧硬违规 0 处；分镜吻合度的偏差主要是这一类，另有 3 镜（14/19/10）确实需要重拍，已重拍。
7. **返工记录**：首轮 26 镜里 16 镜因「真实照片 vs 文字描述」打架导致小六二偏蓬松偏胖，
   另有 3 镜（镜02 传单印字 + 两足站立、镜08/09 甲乙两足站立、镜20 上铺是成年边牧而非幼犬、
   镜14 拍成空桌面、镜19 缺拉杆箱）需要重拍。累计重投约 1.1 万 credits，详见 `docs/额度与成本.md` 第八节。
